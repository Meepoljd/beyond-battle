01 / 演习准备

本版由确定性规则驱动，不调用大模型、不产生 API 费用。演习伤亡不带入下一局。

第一次演习？一分钟了解规则
  1. 选择指挥官，为其下达任务；命令只有送达后才执行。
  2. 每次点击推进 5 分钟。下属会依收到的任务自主行动。
  3. 战场时间 20–30 分钟有固定通信中断，旧情报会继续显示时间戳。
  4. 守住雾河桥直到第 16 回合；敌军独占桥梁 2 回合即失守。
  5. 结束后查看事实与战报，确认要带入下一局的经历。
